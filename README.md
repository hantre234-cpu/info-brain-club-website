# Info Brain Club Website

A clean, responsive static website for the Info Brain Club — a community for people interested in sharing knowledge, events, and resources related to technology and learning.

Built with HTML, CSS, and JavaScript.

---

## Project Overview

This repository contains the website for the Info Brain Club. It is a front-end static site intended to showcase club information, upcoming events, resources, and contact details. The site is structured with semantic HTML, styled with CSS, and enhanced with JavaScript for interactive behavior.

Language composition (approximate):
- CSS: 35.6%
- HTML: 33.9%
- JavaScript: 30.5%

---

## Features

- Responsive layout for desktop, tablet, and mobile
- Event or announcements section
- Resources or links section
- Contact / join form (static or integrated with a backend / form service)
- Lightweight and accessible markup

---

## Tech Stack

- HTML5
- CSS3 (flexbox/grid, responsive design)
- Vanilla JavaScript

No build tools are required — this is a simple static site.

---

## Getting Started (Local Development)

1. Clone the repository:

   git clone https://github.com/hantre234-cpu/info-brain-club-website.git
   cd info-brain-club-website

2. Open index.html in your browser, or serve the folder with a simple local server. Example using Python:

   # Python 3
   python -m http.server 8000

   Then open http://localhost:8000 in your browser.

3. Make changes to HTML/CSS/JS files. Refresh the browser to see updates.

---

## Deployment

This static site can be deployed using GitHub Pages:
1. Push your changes to the repository.
2. In the repository settings, enable GitHub Pages from the main branch (or `gh-pages` if you use that branch).
3. Optionally set a custom domain.

Other hosting options: Netlify, Vercel, Surge, or any static-file host.
